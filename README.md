# File-Based-Attendance-Management-System
A C++ console application for recording and managing student attendance data using text files as the primary storage format.
This project includes essential features such as:
- CRUD operations for student data and attendance records
- Search functionality
- Sorting of records
All data is saved and managed through .txt files, which are accessible and human-readable.

## 🔧 Features
- ➕ Add new student and attendance records
- 📝 Update or delete existing data
- 🔍 Search for students or attendance by name
- 📊 Sort records by various fields
- 💾 All operations are saved to and retrieved from .txt files
